## Available Extension

### [Upcoming Song](upcomingSong/README.md)

Shows the next playable track beside the currently playing song. Select it to skip ahead.

<p align="center">
    <a href="upcomingSong/README.md">
        <img src="upcomingSong/smallPreview.png" height="100" alt="Upcoming Song preview" />
    </a>
</p>

## Installation

Install **Upcoming Song** from the Marketplace's **Extensions** tab, or follow the [manual installation guide](https://spicetify.app/docs/advanced-usage/extensions/#installing).
