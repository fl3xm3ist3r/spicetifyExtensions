## Features

- Displays the next playable track's cover, title, and artists.
- Refreshes when playback or the queue changes.
- Select the track to skip to it.
- Hides while Spotify is fullscreen and returns when fullscreen closes.

## Installation

### Spicetify Marketplace

Open the Marketplace in Spotify, go to **Extensions**, and search for **Upcoming Song**.

### Manual installation

Copy `upcomingSong.js` to your Spicetify `Extensions` folder, then enable and apply it:

```sh
spicetify config extensions upcomingSong.js
spicetify apply
```

See the [Spicetify extension guide](https://spicetify.app/docs/advanced-usage/extensions/#installing) for details.
